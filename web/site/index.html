Sáu tướng, mỗi tướng bốn chiêu

Mua đồ ở nhà hoặc shop ẩn, ghép đồ từ thành phần, soạn sẵn bộ đồ, mua nhanh bằng một chạm.

Cách cài

  1. Tải APK bằng nút ở trên (khoảng 65 MB, nên dùng Wi-Fi).
  2. Mở file vừa tải. Lần đầu, Android hỏi cho phép cài ứng dụng từ trình duyệt hoặc trình quản lý file — chọn Cho phép.
  3. Cài và mở game. Từ đó, mỗi khi có bản mới, game tự hiện nút Cập nhật.
